# Brain Rush

Free, fast and useful online tools for everyday tasks.

## Current release
A responsive English-first utility website with a browser-first architecture.

## Tools
Calculator • Unit Converter • Currency Converter • Age Calculator • Password Generator • Text Counter • Percentage Calculator • BMI Calculator • Date Difference • QR Generator • Timer & Stopwatch • Random Number • Case Converter • Color Picker

## Principles
- No account required
- Responsive design
- Dark/light mode
- Most calculations run locally
- SEO-ready HTML
- Ad-ready layout without intrusive advertising

## External services
Currency conversion uses the public Frankfurter API. QR generation loads QRCode.js from cdnjs only when the QR tool is opened.

## Next roadmap
Dedicated SEO URLs for every tool, richer metadata, accessibility refinements, analytics consent controls, PWA caching, and monetization/AdSense preparation.
